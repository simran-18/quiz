Follow these steps to set up and run the quiz frontend application locally:

Step 1: Clone the Repository

Open your terminal and run:

git clone https://github.com/simran-18/quiz.git

Step 2: Navigate into the Project Directory

cd quiz

Step 3: Checkout the dev Branch

git checkout dev

Step 4: Install Dependencies

npm install

(If you're using Yarn, use yarn install instead.)

Step 5: Start the Development Server

npm run dev

This will start the application. Open your browser and go to:🔗 http://localhost:5173 (or the port displayed in the terminal)
